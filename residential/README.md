# DealCheck — Residential Flip

An iPhone-first residential property acquisition and house-flip screening app for New Zealand.

## Included

- Editable buy price, forecast sale price and 6–8 month holding period
- Detailed acquisition, finance, renovation, holding and selling costs
- Gross sale amount, gross profit, final net profit, cash required, cash ROI and break-even sale price
- Dedicated tax allowance using a default 28% rate, with pre-tax and after-tax profit shown separately
- Green / amber / red result using editable profit and ROI targets
- Automatic draft saving plus up to 30 named deal snapshots on the device
- CSV report sharing through the iPhone share sheet, including Google Drive
- Print-friendly report for PDF saving
- Installable Home Screen app with offline support after the first successful load

## Use on iPhone

Open the GitHub Pages address in Safari, tap **Share**, then **Add to Home Screen**.

To save a deal to Google Drive, tap **Share / save report** and select Drive from the iPhone share sheet. The full input and result set is saved as a CSV file that also opens in Google Sheets.

## Calculation model

The calculator uses simple interest over the holding period. Purchase debt is assumed to be fully drawn. Any renovation finance is assumed to be half drawn on average. Agent commission is a flat percentage of sale price. The optional tax field is only a provisional percentage allowance, not a tax calculation.

This is a quick screening model, not a valuation, lending assessment, GST calculation, tax opinion or full development feasibility.
